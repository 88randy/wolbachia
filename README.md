# Wolbachia

Traceability platform for the *Aedes aegypti* / Wolbachia control program (Mexico).
This repo holds the field app (React Native, Android) and the shared backend (Django + DRF).
The web app is designed in parallel and consumes the same backend.

- Design (Claude Design canvas): "Wolbachia · App Repartidor" — Ronda 1.
- Workflow: spec-first. Every change starts as a GitHub Issue (9 sections) and lands through a PR linked to it.
- Bootstrap issues: `scripts/create_issues.sh` (bash / Git Bash) or `scripts/create_issues.ps1` (PowerShell).
