# Community activities (B34)

Aggregate attendance observations, never resident identities. `zone_id` names a
real Block; its immutable version and type snapshot retain the capture context.
One writer and an origin-bound command receipt serve HTTP and field ingestion.
Current paired action scope governs every use; retained facts grant no authority.

Operational rows are insert-only. Correction appends a terminal event and keeps
the reported Incident/link and independent holds. Pending sources have no activity
or totals. Only actual source-backed activity uses the existing courier history
publisher; HTTP facts never fabricate a FieldEvent or courier. Real PostgreSQL
constraints and concurrency require CI; database-free checks do not qualify them.

Public list/detail use community_activity.read and actual full paired scope before
filters/count/order/page. Totals always exclude voids and sum the complete filtered
set as exact digit strings; include_voided only changes display rows/count. Type,
Block version, local date and timezone are captured facts, not fresh mutable labels.
Complaint Incident references are independently redacted using current incident.read;
the link does not reparent evidence or change a case/hold. Free text cannot be certified
PII-free: enter only nonidentifying agreements, correct mistakes through the existing
reasoned lifecycle and follow the organization's privacy response; no erasure service
is silently claimed by immutable audit.

HTTP locks sorted real Users→actor Device/Session/Pair→preplanned real sources→Org
NO KEY NOWAIT→original courier TRY→domain. Source ingestion keeps its existing
identity/courier boundary and repeats the new action+pair gate before pending paths.
No account/source discovery or external I/O happens below domain locks. Deferred
completion requires actual receipts/source links, and populated reverse refuses
erasure. Released migrations, root2 and all six B04 parents are unchanged.

The seed-once ledger adds read/create/void only to admin; read/create to promoter/
courier; read/void to supervisor/coordinator. Existing revoked/custom/government
grants and scopes remain. No live seed execution is part of this delivery.

Owners: test_community_b_34 owns closed wire, original command/date, public ACL/link,
pending/review/source cancellation, latest source history/totals and both lock winner
orders. test_community_migrations_127 owns real upgrade/raw SQL/protected reverse.
Existing seed/OpenAPI/registry owners retain their policies and gain only this contract.

Review inspection proves historical Incident linkage without inventing a reviewer;
acceptance separately requires the actual review actor's current paired Incident
read before effects. Every B34 correction requires normalized 10-visible-character
wording (at most 1000), including cancellation of an unapplied source. A missing
catalog or BlockVersion observation blocks acceptance, not authenticated source
cancellation. Deferred cancellation completion requires the correction source's
accepted outcome or genuine canonical review receipt in the same transaction.
Public receipt/command JSON rejects null or missing required witnesses explicitly.
