# Independent observations and physical paddle reuse (#115)

This package extends the existing LabCommand, RecountRequest, daily draw and
history owners. It does not create a parallel first-count population, sampler,
uploader, ledger, FieldEvent or authentication lifecycle.

Independent observations retain their real first/request/result/claim frame and
authenticated second or third counter. The exact strict tolerance comparison is
pure; published tolerances and named currently verified methods supply its inputs.
An unavailable independent person, scientific procedure or physical source stays
unavailable. Existing first-pass observations and saved command responses remain
immutable.

Forward physical identity and Bag cycles require actual inventory Piece/debit
proof. Recovery uses the concrete PaddleStockReturn source, never a reversed
SupplyUse, fabricated return acceptance or arbitrary positive movement. Actual
material, QA, scoped authority and verified evidence gate every new physical act.

The full adopted contract is issue115. Read ../README.md, the project engineering
rules and docs/api-conventions.md before changing this owner. PostgreSQL guards,
stock effects and races require fresh CI; pure/collection checks do not execute SQL
or certify an operational biological procedure.

The four adopted decisions are forward typed physical identity/stock return,
immutable per-actor numeric disclosure, distinct independent observations plus a
reasoned exact choice, and late-QA material unavailability. Configuration defaults
to tolerances10/10 only; methods and their new capabilities are never verified by
default. See docs/api-conventions.md for the closed wire and legacy external
assessment. All physical evidence follows verified-unbound B04 then atomic typed
LabCommand binding, not another prepare/idempotency lifecycle.
