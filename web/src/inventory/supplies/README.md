# Supply catalog (W8)

Supply identity, declared unit, biological identity and nullable safety flags are
explicitly authored. No insecticide-free, expiry or chemical default is inferred.
Protocol fields name the configuration and accept only the canonical elapsed
seconds, basis, paired ranges, two ordered windows, biological required fields and
incident-type version choice. The incident chooser uses the action-scoped #270
read contract, not role/incident catalog permissions.

Unknown persisted protocol arrays keep their readable scalar facts and lock
protocol editing. The payload builder also checks this boundary after conflict review. An explicit protocol-only discard preserves identity input and makes the next ordinary save omit protocol. An unrelated save never serializes replacement arrays.
Deactivation uses the real revisioned endpoint after confirmation and retains
historical labels and lots. There is no activation, deletion or stock action.

The parent README maps acceptance criteria to the owning tests.
