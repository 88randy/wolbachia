# W50 trainings (#148)

W50 consumes the merged B03 generated contract. Course definitions resolve an
exact scoped `code` before version reads or publication. Server paging owns
course/version/certificate lists. Immutable versions retain explicit positive
validity seconds, enabled action keys, effective instant and active state.
Organization-wide publication requires explicit `all` in both scope dimensions.

Personal lookup takes genuine authorized subject/context UUIDs: `training.read`
does not grant the personnel directory or evaluation access. Existing verified
owned, unbound B04 evidence UUIDs may be bound by certification creation under
`training.manage` and `field.upload`. The image picker runs actual B04 unbound
authorize/renew, same-buffer authenticated PUT and server finalize before binding.
Explicit aware start/end instants remain unchanged; the backend
owns maximum duration and half-open expiry semantics. Eligibility is a factual
read, never operational permission or historical capture proof.

Every query uses the shared organization-scoped helper with current authorization
and active center. Changing identity retires the private RAM draft owner; scope
changes retire old queries and inaccessible editors while preserving drafts in
still-authorized original contexts. Local authorization-entry tokens plus shared
session revision guards drop stale commands/uploads, including scope ABA changes.
Same-identity reauthentication retains drafts. No write is queued or automatically
replayed. Failed submissions retain fields and do not claim confirmation.

Design deviations: the API has no aggregate expiry counters, personal human
codes, safe subject picker, or notice outcome read.
W50 uses labeled original references and factual eligibility rather than sample
counts, invented names or an action execution control. Action-requirement versions
are server-paged by context; successors retain the selected real revision and
original context, while creation explicitly starts at revision zero. The bounded
publisher replaces only the entered course's acceptable version pins and preserves
every other retained course pin. It does not remove existing required courses.
Backend CAS rejects an outdated selected version.
Current eligibility is hidden and refreshed at the server next-change boundary;
fixed-instant historical/future queries remain factual snapshots.

Tests protect explicit global scope, retained action/validity/evidence request
pins, expiry at the server boundary, scoped person denial, and keyboard errors.
Browser coverage is in `web/e2e/w-05.spec.ts`. No backend or generated API file is
changed; no new dependency is introduced.
